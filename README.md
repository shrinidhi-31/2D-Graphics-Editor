# 2D Graphics Editor in C

## Description
This project is a menu-driven 2D Graphics Editor developed in C using a 2D character array as the drawing canvas.

The canvas is initialized with '_' (underscore) characters, and graphical objects are drawn using '*' (asterisk).

## Features

- Draw Line (Bresenham's Line Algorithm)
- Draw Rectangle
- Draw Triangle
- Draw Circle (Midpoint Circle Algorithm)
- Display Canvas
- Delete Individual Objects
- Modify Individual Objects
- Clear Entire Canvas
- Menu Driven Interface

## Technologies Used

- C Programming Language
- GCC Compiler
- Git & GitHub

## Algorithms Used

1. Bresenham's Line Algorithm
2. Midpoint Circle Algorithm
